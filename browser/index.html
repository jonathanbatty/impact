ABOUT THE PROJECT

IMPACT — the Inclusive Multimorbidity Phenotyping Algorithm and Coding Tool

IMPACT supports ascertainment of long-term conditions in routinely collected healthcare datasets, with packages for Stata, R and Python. This browser provides a searchable view of the project's master codelist.
